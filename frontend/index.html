使用说明

  1. 填写订阅、规则模板和转换器地址，按需设置配置文件名称。
  2. 调整转换选项，按需填写三个处理脚本。
  3. 新建时点击“生成订阅地址”；编辑已有订阅时粘贴短链接并载入，修改后点击“保存到原链接”。

页面输入刷新后清空，可凭原链接和管理 token 重新载入。更新保存成功后，客户端下次更新整份订阅即可获取新配置。另存为新链接不会修改原订阅。请妥善保管订阅地址。

设置管理 token 后，生成、载入和更新配置时需要填写；客户端访问订阅无需 token。转换器必须能从公网访问，并会获得订阅内容，请选择可信服务。

脚本需定义同步 transform(input, context)，没有网络、文件系统、Node.js 或 npm，不支持 async。后端生成链接时检查语法，使用链接时才执行脚本和公网地址检查。

三个脚本合计最多 64 KiB，链接长度不会随脚本增长。生成成功不代表上游可访问或脚本执行成功。

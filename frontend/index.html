生成与复制

参数和脚本将保存到后端，并生成订阅短链接。修改输入后，需要重新生成。

复制后粘贴到 Clash / Mihomo 客户端的订阅设置中。

持有链接的人可以获取订阅配置，请勿公开分享。页面刷新后，已生成的链接仍可使用。

使用说明

  1. 填写订阅、规则模板和转换器地址。
  2. 调整转换选项，按需填写三个处理脚本。
  3. 点击“生成订阅地址”，复制到 Clash / Mihomo 客户端；也可以下载 YAML 配置。

页面输入刷新后清空；点击生成会将参数和脚本保存到后端，返回可持续使用的短链接。请妥善保管订阅地址。

脚本需定义同步 transform(input, context)，没有网络、文件系统、Node.js 或 npm，不支持 async。后端生成链接时检查语法，使用链接时才执行脚本和公网地址检查。

三个脚本合计最多 64 KiB，链接长度不会随脚本增长。生成成功不代表上游可访问或脚本执行成功。
